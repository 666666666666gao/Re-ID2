## 用户目标与第一轮研究合同

以 DeMo 为 baseline，使用已有 RGBNT201、RGBNT100、MSVR310 和预训练权重，训练50轮并选择验证指标最佳 checkpoint。优先检验同参数、同输出维度的“完整 DeMo＋普通频域分支”与“双轴分工＋联合路由”。第三模块以条件协作为核心；第一轮不加入条件贡献监督，避免同时改变结构和训练目标。

待验证主张：模态关系与频带之间的非独立路由，以及双轴职责分工，能改善身份检索。第一轮只有结构组合对照，不能单独归因于交互项，不能宣称信息论协同、因果效应或 SOTA。普通分支与双轴分支参数相等不代表 FLOPs 相等，计算量另行测量。首轮单seed42，稳定性尚待独立重复支持。

## 数据协议与 checkpoint 规则

本轮为开发对照，官方测试集不用于选择checkpoint或设计频带。RGBNT201沿用已有141训练身份/30开发身份。RGBNT100、MSVR310沿用已有训练集OOF fold0的heldout身份，固定为开发集；其他训练身份用于拟合。每个开发图库保留所有heldout记录，包括无合法正样本的身份作为干扰项；查询只包括有合法正样本的记录。RGBNT排除同身份且同摄像头记录；MSVR310排除同身份且同场景记录。

## 实现

- 继承完整 DeMo 的共享CLIP主干、PIFE、七种模态关系HDM和ATMoE。
- 对16×8或8×16二维patch网格显式FFT分频，径向频带为≤0.125、(0.125,0.25]、>0.25 cycles/patch。不是对CLS向量FFT，也不是传感器电磁频段。
- 频带values经过LayerNorm、Linear、GELU，再以注意力汇总；避免直接全局平均理想高通响应。频域证据按RGB/NIR/TIR分别形成，在每个来源内部进行跨频注意力。
- ordinary使用完整DeMo原HDM/ATMoE；额外容量全部在频域分支内进行自调制和跨频建模。频域输出与完整DeMo描述子直接拼接。
- dual复用七种HDM模块，在各频带上访问过滤后的patch values。频域证据V(S,b)只汇聚集合S内来源。双向线性消息分别以频域、模态关系证据为条件。
- 两端共同基础路径z0是DeMo的三模态PIFE表示1536D。ordinary额外完整运行原全频HDM/ATMoE；dual将同一HDM/ATMoE的输入访问改为频带感知，不另外增加全频HDM旁路。比较同时改变分工与联合路由，不能把结果单独归因为psi。
- 联合路由logits=a(S)+c(b)+psi(U(S,b),V(S,b))，在7×3表上统一softmax；关闭psi时恢复可分离乘积。外层两个sigmoid门允许两类专家同时有效。
- ordinary/dual构造相同参数对象，使用相同初始化种子和5632D输出。ordinary内也实际使用匹配的额外容量，避免用闲置参数凑相同计数。
- 训练保留标签平滑CE＋soft Triplet，使用作者的Adam参数分组和50轮noise-cosine调度。基础DeMo监督继续保留，新增完整融合和频域汇总监督；两增强模型损失相同。
- 三模态数据使用相同几何增强和擦除随机抽样；按epoch固定sampler与worker随机流，并保留batch文件名序列检查两端预算和采样一致性。

## 发现和修复的问题

1. 原代码CLIP加载路径硬编码为作者机器目录，当前服务器没有该路径。最小修复：从cfg.MODEL.PRETRAIN_PATH_T读取，指向已安装权重。没有添加新的fallback。
2. 原MSVR310旧metrics路径使用np.str并写rank list文件。新入口复用项目已存在的ground-truth排序评估器，传入scene作为排除字段，得到相同的同身份/同场景规则；不改旧研究的metrics文件。
3. 原项目是多年TriFusion研究导出，含大量封存实验和老服务器路径。新实验建立独立目录，原项目及历史结果不变。
4. 新路由打分层的三个标量bias会在softmax中抵消，属于无效容量。审查指出后，在两端同时移除；不以无效参数凑相同计数。
5. RGBNT100作者配置为batch128、30轮；本轮在入口明确统一batch64、MAX_EPOCHS50，使实际训练循环与调度一致。保留作者各数据集其他优化参数；这是同预算开发比较，不声称作者原训练配方复现。
